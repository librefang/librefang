Media placeholders no longer carry the Telegram bot token: `content_to_text` and the `dispatch_message` attachment fallback render `bot<id>:<redacted>` in place of the `…/file/bot<id>:<secret>/…` URL the sidecar hands over.
The Bot API puts the credential in the file path, so the URL itself cannot be stripped without breaking the download — but the raw string was reaching the model prompt, the session transcript, the memory writer and `message_journal.jsonl`, and a single voice note was enough to persist it (#8704, #8705) (@nevgenov)
