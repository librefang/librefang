Media placeholders no longer carry the credential a channel puts in an attachment URL: `content_to_text`, the `dispatch_message` attachment fallback and the download-failure log render `bot<id>:<redacted>` in place of Telegram's `…/file/bot<id>:<secret>/…` path, and `<redacted>` in place of Discord's `hm` signature.
The Bot API puts the credential in the file path, so the URL itself cannot be stripped without breaking the download — but the raw string was reaching the model prompt, the memory writer and `message_journal.jsonl`, and a single voice note was enough to persist it (#8704, #8705) (@nevgenov)
