Text synthesized from a thinking-only model response is now terminal, so it ends the turn instead of keeping it alive.
When a model returned only reasoning with no native text and no tool calls, the OpenAI-compatible driver synthesized a text block from the thinking. The agent loop could then re-promote that text into a tool call via text-based tool-call recovery, or nudge it into a retry, even though the model had already answered. `CompletionResponse` now carries `text_synthesized_from_thinking`, set at both synthesis sites; the loop skips text recovery and retry classification when it is set, and delivers the synthesized answer as-is.
