A configured sidecar channel's Configure drawer could open on a form with nothing in it and still offer a live Save, and even with fields in it, saving an edit was rejected unless every workspace token was re-pasted from scratch.
A drawer that opens but cannot be edited is worse than no drawer at all: the gear icon is a promise that this is the place to change the setting, so an operator who finds an empty panel with an enabled Save concludes their configuration is corrupt, or clicks Save and gets an error naming a token they never touched — and either way they still have to go and hand-edit `config.toml`, having first spent time proving the dashboard would not do it.
A configured row now publishes the same schema provenance a discovery row always has, so the drawer explains an empty form and disables the Save that could only have failed; and a required secret left blank is accepted whenever the instance already has one stored, which is what the drawer's own "leave blank to keep" placeholder had been promising.
