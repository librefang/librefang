Registry sync, hand `base = "<template>"` resolution, and the hands registry's agent-base lookup all now resolve `librefang-registry`'s agent-templates directory under either name: the canonical `agent-types/` (preferred) or the legacy `agents/` (fallback, with a warning).
Previously each site did a bare `registry_cache.join("agents")` + `.exists()` check, so the day upstream renames that directory the check silently returns false and the whole block is skipped — a fresh install would end up with zero preinstalled agents and no warning or error anywhere, and hands whose agents declare `base = "<template>"` (e.g. `devteam`) would drop out of routing.
The new shared helper, `librefang_types::registry_paths::resolve_agent_types_dir`, also logs loudly when neither directory exists, so that failure mode is now distinguishable from a registry that genuinely ships no agent templates (#8000) (@DaBlitzStein)
