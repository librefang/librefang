`/goal` carried `Scope::CLI` in the command registry with no matching arm in the TUI chat runner, so typing `/goal ship the release` in `librefang chat` passed the pre-flight lookup and hit `unreachable!()`, panicking with the terminal left in raw mode; it now creates and starts the goal when attached to an in-process kernel, and answers with a clear message instead of a nonsense reply when attached to a remote daemon, which has no endpoint for it yet.
`/think` and `/exit` were pinned to dashboard execution paths (`Backend` and `Client` respectively) that do not exist — the dashboard's WebSocket command handler has no `think` arm, and the SPA has no client-side `/exit` branch — so selecting either from the slash menu rendered an error or spent an LLM turn on the literal text; both now carry `dashboard_exec: None`, the same state as `/status`, until real handlers exist.
A comment on `/new` claimed it resets the agent session the same way on every surface, which is the opposite of what dashboard `/new` (mints a new session id) and TUI `/new` (clears history at the same session id) actually do.
The test guarding non-channel commands against leaking into the channel-visible set re-derived its own filter predicate and could never fail; it now compares against an explicit golden list, the same pattern already used for the channel-visible set itself. (#7996) (@DaBlitzStein)
