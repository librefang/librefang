Turns that run with no tool channel — the ephemeral `/btw` path and every caller posting `"ephemeral": true` — used to answer a work request by writing the tool call as text. The leak guard's replacement sentence then told the user to send the request again or to `/reset` the session, though re-sending lands on the identical tool-less path and an ephemeral turn has no session to reset. Such a turn now gets its own sentence, and carries a short note that the tool channel is off, so the model answers in text or points the user at the main chat instead of writing a call it cannot make.
