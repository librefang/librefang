A config group's section list now decides the order its sections render in, not only which of them render: the editor had been drawing every group in its own canonical sequence, so General listed Lifecycle before Response format and got the reverse, and the callers had no way to say otherwise.
Every folded section now carries the number of fields it holds, counting the fields inside its own "Advanced" fold because that is what opening the section reveals, and a section with no fields shows no count rather than a "0" that reads as a section which failed to load.
