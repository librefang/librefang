CI now refuses a pull request whose commits carry Claude / Anthropic attribution, closing the route by which 31 of the last 500 commits on `main` acquired a `Co-authored-by: Claude` trailer despite a `commit-msg` hook that forbids exactly that.
Two gaps let them through: `core.hooksPath` is opt-in per clone, so a fresh clone or an agent worktree pushes with no git-side enforcement at all; and GitHub composes the squash-merge commit server-side, appending `Co-authored-by:` for every non-primary author in the branch — so one Claude-authored commit anywhere stamps the merge commit with attribution no local hook can see.
The check drives the existing `scripts/hooks/commit-msg` once per commit rather than restating its rules, because a second copy of that regex is the drift its own comments warn about.
It runs on `pull_request` on purpose: once the trailer is on `main` the history is public and the remedy is a force-push to a protected branch, whereas the PR stage is one rebase. (#8147) (@houko)
