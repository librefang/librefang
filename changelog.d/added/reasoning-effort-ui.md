The chat composer gains a reasoning-effort control beside Deep Thinking: it lists the levels the active model allows — its catalog `supported_efforts` set, with `none` dropped outright when `off_allowed` is false or `mandatory` is true (xAI, Kimi K3, Gemini 3+), and the canonical `none`/`minimal`/`low`/`medium`/`high`/`xhigh`/`max` only when an older daemon declares nothing — and a level outside the offered set is shown as current state but never offered, since the backend coerces one that arrives to the nearest supported level.
  It splits the two things operators kept asking for in one place: clicking a level arms it for the next message only, sent as `reasoning_effort` on the turn and consumed after it, while a pin on the row fixes the level to the session through `PATCH /api/sessions/{id}/reasoning` (`{"reasoning_effort": …}`), with a pinned banner and an un-pin action and the session's stored value read back on load.
  The agent editor's Thinking section gains the same selector for `[thinking] reasoning_effort` — the level every automated turn runs with — with an inherit option so the key stays absent (the model's `default_effort` applies), a one-click clear, and the chosen model's level list when the catalog has one; a manifest still carrying the deprecated `reasoning_mode` spelling loads into the same field and is re-emitted canonically on the next save.
  Level names stay the technical wire spellings (None, Minimal, Low, Medium, High, xHigh, Max) in every language, because the level a model documents is the string the API takes (#8617) (@DaBlitzStein)
