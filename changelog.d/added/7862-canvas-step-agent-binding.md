The Canvas step editor now chooses how a step finds its agent — a specific running instance, or an agent name resolved when the step runs — and can set the step's session independently of the agent's own default, including a fresh session for every run.
Binding by name is what survives a respawn: an agent's id changes when it is killed and started again, its name does not, so a workflow authored against a name keeps working where one pinned to an id quietly stops resolving.
The source is a stated choice rather than something inferred from whichever field happens to be filled in, which is what makes it switchable in both directions (#7862) (@houko)
